# B2B Router integration

1. Install requirements/dependencies [`b2brouter-python`](https://github.com/ribaguifi/b2brouter-python/):

```bash
pip install wheel
pip install git+https://github.com/ribaguifi/b2brouter-python.git
```

2. Configure B2BRouter API settings:
```python
B2BROUTER_API_KEY = "api-key-provided-on-developer-settings"
B2BROUTER_API_URL = "staging VS production URL"  # "https://api-staging.b2brouter.net"
B2BROUTER_ACCOUNT_ID = "1234"  # Account ID for B2B Router integration.
```
